Cursor Dodger

An Elementor widget that fills a box with circles which run away from your cursor. Move your mouse into the area below.

Install on WordPress

Grab the plugin folder at cursor-dodger/, zip it, and upload it via Plugins → Add New → Upload Plugin on a site that already has Elementor active. A new Cursor Dodger widget will show up in the Elementor editor.
